# FixMate by ResolveX

A modern, animated, role-aware issue and ticket management experience built with React, TypeScript, Vite, TailwindCSS, Redux Toolkit, and a curated design system.

## Getting started

```bash
npm install
npm run dev
```

The project ships with mocked data services so you can explore the dashboards, issues, Jira integration flows, and RBAC-protected pages immediately.

## Scripts

- `npm run dev` – start Vite in development mode.
- `npm run build` – type-check and build the production bundle.
- `npm run preview` – preview the built app.
- `npm run lint` – run ESLint with the configured TypeScript rules.

## Tech highlights

- React 18 + TypeScript + Vite.
- Redux Toolkit for auth + theme state.
- TailwindCSS with custom theming, animated AppShell, and reusable UI primitives.
- Framer Motion animations, Recharts dashboards, Headless UI dialogs, and lucide icons.
- React Hook Form + Zod for form validation.
- Mock API layer representing projects, issues, users, dashboards, and Jira operations.
- Light/Dark theme toggle persisted in local storage.
